## Getting Started

This is the code for "From Automated Data Extraction to Inverse Design: Discovering Ultrahigh Glass Transition Temperature Polyamides Enabled by Large Language Models"

![image](https://raw.githubusercontent.com/zhf3564859793/LLM4High_Tg_PA/main/Figure/Figure%201.jpg)

This work presents an integrated framework that combines large language models (LLMs), machine learning, and molecular dynamics simulations for the discovery of high-glass-transition-temperature (high-$T_g$) polyamides. The framework consists of four main parts: automated literature information extraction, forward property prediction, inverse molecular design, and molecular dynamics validation.

### Prerequisites

The Python-based workflows require a standard scientific Python environment. 
```sh
python = 3.11.13 
```
Typical packages include:

```sh
pip install numpy pandas scipy scikit-learn matplotlib rdkit openai torch shap
```

For molecular dynamics simulations, the following software is required:

- GROMACS
- Packmol

### Installation

1. Clone this repository to your local machine:

```sh
git clone https://github.com/zhf3564859793/LLM4High_Tg_PA.git
```

2. Navigate to the project directory:

```sh
cd LLM4High_Tg_PA
```

## Usage

## 1. LLM-Based Polyamide Information Extraction

The `1. LLM_Extraction` folder contains the workflow for automatically extracting polyamide information from scientific literature using large language models.

The main notebook is:

```text
LLM_extraction_260430 (final version).ipynb
```

## 2. Forward Model

The `2. Forward Model` folder contains the machine-learning workflow for predicting the glass transition temperature of polyamides.

The main notebook is:

```text
QSPR_260506.ipynb
```

Polyamide structures are converted into molecular representations and used to construct quantitative structure-property relationship (QSPR) models.

The workflow includes molecular representation generation, machine-learning model training, cross-validation, test-set evaluation, and model interpretation.

The optimized $T_g$ prediction model achieved an $R^2$ of 0.8726 on the manually annotated test set.

The trained forward model is further used to evaluate polyamide structures generated by the inverse design model.

## 4. Molecular Dynamics Simulation

The `4. MD simulation` folder contains the all-atom molecular dynamics workflow used to independently validate the glass transition temperatures of selected generated polyamides.

The simulations are performed using GROMACS with the General AMBER Force Field (GAFF).

The molecular dynamics workflow includes:

1. Preparation and relaxation of a single polymer chain.
2. Construction of the bulk amorphous polymer system using Packmol.
3. Energy minimization.
4. High-temperature NVT equilibration at 900 K.
5. High-temperature NPT equilibration at 900 K and 1 bar.
6. Continuous cooling of the polymer system.
7. Extraction of polymer structures at different temperatures.
8. Independent NPT simulations at each sampled temperature.
9. Calculation of the density-temperature relationship.
10. Estimation of $T_g$ using bilinear fitting of the density-temperature data.

The simulation scripts are located in:

```text
4. MD simulation/scripts/
```
